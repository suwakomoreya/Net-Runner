# Net Runner 
A terminal caesar decipher game inspired by Cyberpunk.

* Upgrades/accessories
* Difficulty levels
* Data saving

The program is small and requires nlohmann/jsons library for saving data, everything else is part of the C++ library.
Required libraries:
https://github.com/nlohmann/json
msys2 ucrt64 gcc c++ compiler
1. install dependencies `pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-curl mingw-w64-ucrt-x86_64-nlohmann-json`
2. navigate to directory `cd path/to/CaliCityGlaze`
3. compile `g++ main.cpp -o CaliCityGlaze.exe -lcurl`
4. run application `./main.exe

HOW TO RUN
----------
Double-click Net-Runner.exe (Windows x64).
Keep Net-Runner.exe, the included DLLs, and the data folder together in
the same directory.

CONTROLS
--------
Up / Down     Navigate menus
Enter         Select / submit answer
Esc           Back
Backspace     Delete a character
